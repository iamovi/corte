Corte is a sans built from straight strokes, flat ends and cut corners. It holds its shape at large sizes and stays clear in short lines of text, with bold for emphasis and italic for voice. 0123456789

Use it

Corte is a family of four styles. Use it from the CDN or host the files yourself.

Stylefont-weightfont-style
Regular400normal
Italic400italic
Bold700normal
Bold Italic700italic

1. Quick CDN (recommended)

Add this link tag inside your HTML <head>. It loads all four styles; browsers only download the ones your page uses.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/iamovi/corte@1.1.0/css/corte.css">

2. Self-host

Copy the fonts/ folder and add one @font-face per style (or just copy css/corte.css):

@font-face {
  font-family: "Corte";
  src: url("fonts/Corte-Regular.woff2") format("woff2"),
       url("fonts/Corte-Regular.ttf") format("truetype");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Corte";
  src: url("fonts/Corte-Italic.woff2") format("woff2"),
       url("fonts/Corte-Italic.ttf") format("truetype");
  font-weight: 400;
  font-style: italic;
  font-display: swap;
}
@font-face {
  font-family: "Corte";
  src: url("fonts/Corte-Bold.woff2") format("woff2"),
       url("fonts/Corte-Bold.ttf") format("truetype");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Corte";
  src: url("fonts/Corte-BoldItalic.woff2") format("woff2"),
       url("fonts/Corte-BoldItalic.ttf") format("truetype");
  font-weight: 700;
  font-style: italic;
  font-display: swap;
}

3. Apply it

body {
  font-family: "Corte", sans-serif;
  font-synthesis: none; /* never fake bold or italic */
}

h1, strong { font-weight: 700; }
em         { font-style: italic; }
.note      { font-weight: 700; font-style: italic; } /* Bold Italic */

Install on your computer

Download the .ttf files, open them and install. Word, Figma, Photoshop and the like list the family as Corte with Regular, Italic, Bold and Bold Italic.
