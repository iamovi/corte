Corte is a bold sans built from straight strokes, flat ends and cut corners. It holds its shape at large sizes and stays clear in short lines of text. 0123456789

Use it

Use Corte in your projects directly via CDN or by downloading the files.

1. Quick CDN (Recommended)

Add this link tag inside your HTML <head>:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/iamovi/corte@1.0.0/css/corte.css">

2. Self-Host via CSS

Download the files and add the font-face definition to your stylesheet:

@font-face {
  font-family: "Corte";
  src: url("fonts/Corte-Regular.woff2") format("woff2"),
       url("fonts/Corte-Regular.ttf") format("truetype");
  font-display: swap;
}

body {
  font-family: "Corte", sans-serif;
}
