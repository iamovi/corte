Facet - website and font files

index.html          the preview website (open it in a browser)
css/style.css       styles (white background, black text)
js/main.js          tester and character grid
fonts/              Facet-Regular.woff2 (web) and Facet-Regular.ttf (install)

Host it: upload this whole folder to GitHub Pages, Netlify, Vercel or
Cloudflare Pages. Keep the folder structure as it is.

Use the font in your own site: copy the fonts/ folder next to your CSS and
add the @font-face rule shown in the "Use it" section of the page.

Facet is an original typeface, free to use for personal and commercial projects.
